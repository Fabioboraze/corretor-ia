# CORRETOR IA — MVP 0.1

Assistente de marketing e vendas imobiliárias com IA.

## O que já faz
- Cadastro do imóvel (Motor do Imóvel)
- Modo Alto Padrão, Direto e Investidor
- Campanha completa
- Roteiro de Reels
- WhatsApp
- Follow-up
- Tratamento de objeções
- Anúncio

## Como rodar
1. Instale Node.js 22+
2. Rode `npm install`
3. Copie `.env.example` para `.env.local`
4. Coloque sua chave da OpenAI em `OPENAI_API_KEY`
5. Rode `npm run dev`
6. Abra `http://localhost:3000`
